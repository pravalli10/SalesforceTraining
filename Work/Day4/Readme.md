### 1. What is LWC?

**LWC stands for Lightning Web Components.** It is a Salesforce framework used to build fast, reusable, and interactive user interfaces using standard web technologies like **HTML, JavaScript, and CSS**.

### 2. What did you build?

I built an **LWC component for the Placement Management System** to display and manage placement-related information in a simple user interface.

### 3. Which file contains HTML?

The **`.html` file** contains the HTML code.

Example: `placementComponent.html`

It defines the **structure and user interface** of the component.

### 4. Which file contains JavaScript?

The **`.js` file** contains the JavaScript code.

Example: `placementComponent.js`

It handles **logic, user actions, data, and events**.

Today, I learned:

* What **Lightning Web Components** are.
* How to create an **LWC component**.
* The purpose of **HTML, JavaScript, CSS, and XML files**.
* How HTML creates the UI and JavaScript handles the logic.
* How LWC can be used to build a user-friendly interface for a Salesforce application.
